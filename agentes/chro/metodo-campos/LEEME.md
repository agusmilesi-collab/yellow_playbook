# Método Campos HR (copia de referencia para el CHRO)

Copia de cuatro documentos del método de Campos HR, hecha el 2026-11-12 para que el CHRO de Yellow los lea en cada latido, también desde la nube. La fuente es el repo de Campos HR (`method/`), que no está en GitHub; si el método cambia allá, hay que volver a copiar estos archivos.

| Archivo | Para qué lo usa el CHRO |
|---|---|
| `framework.md` | El método completo: la estructura se deriva de la cadena de valor, función huérfana, agrupamiento de capacidades en puestos, accountability, segregación de funciones, alcance de control, contratar o tercerizar |
| `cadenas-tipo.md` | Plantillas de cadena de valor según el tipo de negocio (Yellow es un "taller": resuelve problemas únicos por cliente) |
| `perfiles-tipo.md` | Perfiles tipo de puestos, para escribir el criterio (competencias) de cada uno |
| `modelo-operativo-y-gobierno.md` | Traspasos entre puestos y matriz de responsabilidades (una sola A por resultado) |

Cómo se aplica a puestos ocupados por agentes: `../diseno-de-agentes.md`.
